**Update:** meum 0.4.0 and later offer this version themselves (Settings ▸ Updates, or meum ▸ Check for Updates…). New installs: download `meum-0.5.4-arm64.dmg` below, open it and drag meum to Applications. Needs Apple Silicon and macOS 14 or later. Signed with a Developer ID and notarized.

## New

- **Workspace icons in the expanded sidebar.** Settings ▸ Sidebar ▸ Workspace icons shows each workspace's icon before its name, as the collapsed sidebar does.
- **A Tips page for Go to Workspace (⌘P).**

## Changed

- The sidebar's scroll bar, and the one in Go to Workspace, is always the thin one that fades out, also when macOS is set to show scroll bars all the time.
- A new Claude session is told when its workspace has no icon or colour yet, so it can give it one.
