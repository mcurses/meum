**Update:** meum 0.4.0 and later offer this version themselves (Settings ▸ Updates, or meum ▸ Check for Updates…). New installs: download `meum-0.5.6-arm64.dmg` below, open it and drag meum to Applications. Needs Apple Silicon and macOS 14 or later. Signed with a Developer ID and notarized.

This release also brings everything from 0.5.5, which was not published on its own.

## New

- **Links in terminals.** Hold ⌘ over a web address, a file path or a folder and it is underlined, and a line at the bottom says what a click does. ⌘-click opens it: a web page in your browser, a local one (localhost) in a browser tab beside the terminal, a file in its editor at the line (`path:42:7`), a folder in Finder. ⇧⌘-click does the other thing: shows a file in Finder, opens a new terminal tab in a folder. Right-click a link for both plus Copy. Terminal ▸ Open Link… (⇧⌘O) puts a letter on every link on screen. Relative paths are looked up from the terminal's folder, then from Claude's. It also works while a program such as Claude Code has the mouse. A click never runs a script or an app: they open as text or show in Finder, and a file or link is only handed to an app installed in Applications (yours or the system's). Settings ▸ Terminal ▸ Open files in picks the editor for text files.
- **Set up for Claude Code on first launch.** The first start offers, once, what meum can wire for Claude Code: the hooks behind the status dots, meum's tools inside Claude Code (for every Claude config folder) and a `~/.local/bin/meum` link so every shell finds the CLI. Each row appears only when it has something to do, and the sheet lists what it wrote. Help ▸ Set Up for Claude Code… opens it again.
- **Programs can offer a widget.** `meum widget offer PATH` (and `widget.offer`) shows a card under the sidebar with the widget's name and the developer team that signed it. Install copies and checks it again and puts it in a folder of its own, never in place of another widget; an update must be signed by the same developer as the widget you have. A team you haven't allowed yet is allowed in Settings ▸ Widgets, as before.
- **Links can open a file.** `meum://open?path=/absolute/path` opens a file in its default app, but only when it lies in a folder you list in Settings ▸ Folders that links may open and ends in an allowed suffix (md, txt and pdf unless you change them). Anything else is refused and logged, without a dialog. The list starts empty, and only the Settings window changes it.
- **A new app icon,** with light, dark, clear and tinted appearances on macOS 26.

## Changed

- A resumed Claude session restarts in the folder it was started in, not in the last folder it moved to.
- After launch, the saved Claude sessions of workspaces you are not looking at start in the background, so they are ready when you switch there.
- A resumed Claude session that has not reported in after 20 seconds shows "waiting for you" rather than nothing.
- A background process that inherited a tab's environment no longer reports itself as that tab's Claude session.
- With workspace icons on, the icon takes the place of the colour stripe instead of sitting beside it.
- The sidebar's port line leaves out the private ports Codex and Claude Code open for themselves; a dev server they start still shows.

## Removed

- `tab.sendText` and `meum tab send`. Use `tab.paste` (`meum tab paste [--submit]`), which types into a tab the way a paste does.
